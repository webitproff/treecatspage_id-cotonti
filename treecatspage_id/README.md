# Tree Cats Page ID (treecatspage_id) v1.2.0

Плагин для Cotonti CMF.

Дерево категорий модуля **Page** с белым списком, **собственной иерархией** и опциональным подсчётом страниц.

## Возможности

- Несколько деревьев с собственным `tree_id`
- Whitelist категорий
- Своя иерархия через `parent_id` (родитель → дочерняя → внучатая)
- Сортировка внутри каждого уровня
- **Подсчёт страниц — настройка на каждое дерево** (радиокнопка Да/Нет)
  - Если «Нет» — SQL `COUNT` не выполняется
- Мультиязычность названий деревьев
- Шаблоны `default` и `sidebar`

## Настройка подсчёта

При создании / редактировании дерева:

> **Вести подсчёт элементов в категории** — Да / Нет

Если «Нет», в `cot_treecatspage_id_build()` блок с запросом к `$db_pages` пропускается, `{ROW_COUNT}` и `{TOTAL_COUNT}` = 0.

## Использование

```html
{PHP|cot_treecatspage_id_render(1)}
{PHP|cot_treecatspage_id_render(1, 'sidebar')}
```

## Обновление с 1.1.0

Выполнить `setup/patch_1.2.0.sql` или переустановить плагин.
